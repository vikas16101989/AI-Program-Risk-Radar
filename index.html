Case Study 01 — Program Risk Intelligence

AI Program Risk Radar

A multi-model program tracker: every model auto-seeds all 12 BIW lines, each line runs a fully editable, explainable 4-phase cascading risk engine with corrective-action tracking, and an executive Dashboard shows both overall program health and the single most critical line side by side. AI briefings are generated through a backend proxy, never a client-exposed key.

Problem

A real program is a model with 12 parallel BIW lines. Leadership needs both "how healthy is the whole model" and "what's the worst thing happening right now" — those are two different numbers, not one.

Structure

Model → Line (12 by default) → Phase (4 gates) → Gate (fully editable, with its own corrective action and due date). Every score is click-to-explain, not a black box.

Production architecture

The browser never talks to Claude directly. It calls a backend function, which holds the API key server-side. See the deployment note for the companion Netlify function.
